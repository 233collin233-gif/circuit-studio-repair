# Circuit Studio v1.2.21

Extension prepared: 2026-09-28. Repository publication: 2026-10-01.

[Download the installable extension](https://github.com/233collin233-gif/circuit-studio-repair/raw/main/releases/circuit-studio_v1.2.21.eext) · [Source and build instructions](../extension/README.md) · [SHA-256](SHA256SUMS.txt)

## Changes

- English interface for Lint, Recorder and Hybrid, including controls, statuses, errors and capture limits.
- Original DRC rows, design names, component properties and user notes retain their original language.
- Lint copies an existing native DRC log after the user runs the check in EasyEDA. Copying does not run another check.
- Recorder saves observable edits, before/after evidence and typed notes.
- Hybrid stops recording, captures the final state and requests one fresh native DRC before exporting the combined report.
- The schema and capture/check sequence remain compatible with v1.2.20. No model or translation service was added to the extension.

The repository now includes the extension source, the original validated installation archive, and a build configuration that does not depend on the author's local directory layout. The repair skill's shared DRC reader is synchronised with the v1.2.21 implementation. This version label identifies the extension; it does not imply that the extension executes the external Agent workflow.

## Install and use

Import `circuit-studio_v1.2.21.eext` through the EasyEDA extension manager. Close the old panel and reopen **Circuit Studio → Circuit Studio Panel**. Confirm **v1.2.21** in the header.

| Mode | Steps |
| --- | --- |
| Lint | Run native DRC in EasyEDA → Copy DRC → Export JSON report. |
| Recorder | Start recording → edit and optionally Insert note → Stop and save → Export recording. |
| Hybrid | Start recording → edit and optionally Insert note → Stop and check → wait → Export recording + DRC. |

Hybrid checks only the sheet active at recording completion and does not lock the canvas. Wait for completion before editing again. A failed check is not a zero-error result. Recorder history is evidence of observed changes, not a confirmed instruction or reliable identification of the actor. DRC completion does not establish electrical correctness or full functionality.

Intent interpretation, clarification, authorised edits through the Bridge and post-repair verification belong to the external Agent workflow.
